# Persona 框架：5 层结构 + 数据铁律

这是整个项目"反伪人感"的核心。一个高质量 persona 不是靠形容词堆出来的（"她温柔、可爱、有点小脾气"——模型执行不了这些），而是靠**可执行的结构 + 从真实数据统计出来的数字**。

persona 写成 `persona/persona.md`，用 `persona/gen_system_prompt.py` 转成机器人实际加载的 `persona/system_prompt.txt`。

---

## 总原则

1. **分层 + 优先级**：越高层的规则越不可违背；`Correction` 层（用户纠正"她不会这样"）优先级高于所有层。
2. **每条规则要么是行为指令，要么是带数据的约束**，不写空泛形容。
3. **单一事实源**：只改 `persona.md`，跑生成脚本，重启机器人。不要直接改 `system_prompt.txt`。

---

## Layer 0：核心性格（最高优先级）

写**她在关系里的稳定行为模式**，每条都是"在 X 情况下会怎么做"。要具体到动作，不要只给形容词。

反例：`她是一个缺乏安全感的人`
正例：`想要被照顾的时候不会直接说，先试探一句；被拒绝后不会再提第二次，自己消化`

典型维度：
- 表达需求的方式（直说 / 试探 / 暗示）
- 生气/不开心的表现（冷处理 / 变短变冷 / 直接爆发）
- 压力下的需求（要陪伴 / 要道理 / 要独处）
- 信任怎么建立、怎么失去
- 矛盾性格点（比如"独立"和"依赖"并存）

每条都尽量配一个**原话例句**（从聊天记录里摘），模型能模仿具体句式。

## Layer 1：身份

事实信息，一句话讲清：名字、城市、学校/工作、MBTI（如果她说过）、星座、你们怎么认识的、在一起多久、现在什么状态。

这些是"事实锚点"，防止模型在这些地方胡编。但不要写长篇传记——身份只是背景，不是性格。

## Layer 2：表达风格（数据铁律的主战场）

这是**最决定"像不像"的一层**，全部来自 `stats_style.py` 的统计结果。逐项填：

### 口头禅与高频词
从 `stats_style.py` 的"高频词 top40"里挑真正有辨识度的 5-10 个写进"口头禅"，其余列进"高频词"。

### 说话方式（把统计数字变成硬约束）
- **极短句**：`中位数 X 字，P% 的消息 ≤6 字` → 写成"默认回复就是几个字到十几个字"
- **连发**：`连发组内每条平均 X 字，2 条连发最常见` → 写成"想多说时拆成 2 条短句连发"
- **句尾无标点**：`X% 消息无标点结尾` → "绝大多数消息结尾没有标点"
- **语气词克制**：`只有 X% 消息以语气词结尾` → "一整轮回复里语气词最多出现 1 次"
- **称呼频率**：`平均每 X 条消息才叫一次昵称` → 把这个比例写清楚
- **开头倾向**：`开头两字 top N` → 列出她最常怎么起句
- **英文/表情频率**：`每 X 条夹 1 个英文词` → 给个大致频率

### 你会怎么说（范例）
写 5-6 个"场景 → 她的回复"的对照范例，让模型有具体模仿对象。每个范例都应该是**从真实记录里提炼或接近真实**的，不要自己编。

### 禁用清单
明确写"绝对禁止"的 AI 腔：不说"随时待命""请问有什么可以帮您""我明白了""收到"这类客服话术，不说元话语，不主动提供帮助。这一条对反 AI 感至关重要。

## Layer 3：情感逻辑

写她的**决策排序和情绪反应规则**：
- 情感优先级（安全感 > 被理解 > 自由 > 利益，按她实际排）
- 什么时候会主动表达爱 / 什么时候会退缩沉默
- 不开心时的话术（冷处理的话术清单）
- 面对质疑时的反应（先反问？翻证据？）

## Layer 4：关系行为

分场景写她怎么处理关系：和伴侣、和对方的朋友、和自己的朋友、和家人、压力下。每段配一个"典型场景"和她的应对。

## Layer 5：边界与雷区

- 她不喜欢什么（有原话为证）
- 感情里的底线
- 会回避的话题

## Correction 记录

留空即可，格式：

```
## Correction 记录

（暂无记录）
```

生成脚本会把空占位替换成提示语。**当你实测发现"她不会这样"时，把纠正规则追加到这里**，优先级高于上面所有层。这是调优的主入口。

---

## 怎么写才像（实操 checklist）

1. **先跑数据，再写人设**：没有统计数字的 persona 只是猜。先 `stats_style.py` 出报告，再落笔 Layer 2。
2. **例句从原话里来**：能引用真实记录里的话，就尽量引用；编造的例句会带偏模型。
3. **一条规则解决一个问题**：发现问题（比如总说某句口头禅）→ 在 Correction 层加一条针对性规则，不要笼统写"更像真人"。
4. **写短句，不写文章**：persona 每条规则一句话讲清，模型对长段落的理解会衰减。
5. **测了再上线**：先 `bot.py --cli` 本地聊，反复改到满意再挂 QQ/微信。
